# DEVIATIONS FROM TRD.md §8, recorded rather than silently applied:
#   - TensorFlow 2.21, not the 2.15 the TRD names. TF 2.15 publishes no macOS/arm64 wheel under
#     the `tensorflow` name, so 2.15 is not installable on the team's dev machines. 2.21 ships
#     Keras 3, which is what the TRD actually asks for.
#   - numpy is pinned BELOW 2.0 because scikit-learn 1.3.2 (the TRD's version) is built against
#     the numpy 1.x C ABI and raises "numpy.dtype size changed" under numpy 2.x. Pinning numpy
#     rather than bumping scikit-learn keeps the Phase 1 results reproducible, since a different
#     scikit-learn changes the Random Forest baseline and the feature ranking.
#     Consequences accepted for that choice: `ml-dtypes` reports an unsatisfied numpy>=2
#     requirement (TensorFlow trains and MultiHeadAttention runs correctly regardless, verified),
#     and shap is held at 0.46.0 because 0.51 requires numpy>=2.
