#     scikit-learn would change the Random Forest baseline and the feature ranking.
#     This makes `ml-dtypes` report an unsatisfied numpy>=2 requirement; TensorFlow trains and
#     MultiHeadAttention runs correctly regardless (verified), so the warning is accepted.
